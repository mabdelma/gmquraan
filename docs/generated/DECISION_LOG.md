## How OPEN items are handled

Per the safe-autonomy rule, an OPEN item does not stop the wave — it stops the
slice that depends on it. Work continues around it, and the dependency is
recorded in `IMPLEMENTATION_WAVES.md` so nothing is silently built on an
unresolved policy.

Specifically: **D-001 and D-003 must be closed before any payroll or ledger
figure is produced.** A payroll engine that computes a number under an invented
statutory rule is worse than no payroll engine, because the number looks
authoritative.
